# Лабораторні роботи з кібербезпеки на Python

Цей репозиторій містить виконання лабораторних робіт з курсу кібербезпеки.

## Structure

```text
cybersecurity-python-labs/
├── .venv/                   # Віртуальне середовище Python
├── shared/                  # Спільні модулі проєкту
│   ├── __init__.py
│   └── student.py           # Дані про студента
├── labs/                    # Каталог лабораторних робіт
│   ├── __init__.py
│   ├── lab01/               # Лабораторна робота №1
│   └── lab02/               # Лабораторна робота №2
│       ├── __init__.py
│       ├── task1.py         # Модель користувача, облікового запису та аутентифікації
│       ├── task2.py         # Аналізатор журналів веб-сервера (Варіант 1)
│       ├── main.py          # Сценарій демонстрації
│       └── data/            # Вхідні дані та звіти
│           └── data_v01/
│               ├── access.log
│               └── web_analysis_report.json
├── .gitignore               # Конфігурація ігнорування файлів для Git
├── README.md                # Опис проєкту
└── requirements.txt         # Список залежностей проєкту
